5. VOICE ALLOCATION
    function: dequeues MIDI ring buffer until it's empty, handled each message independently
            contains MIDI FSM
                relevant MIDI messages: note-on, note-off, status messages
                FSM should handle all other MIDI messages to prevent misalignment or wrong state transitions
            in the event of a note-on or note-off, decodes status messages
                decode: MIDI note number->frequency->phase increment (float)
            raise global new_press/new_release flag
    handled in: main(); long process

6. MIDI HANDLING
    function: ISR triggered upon midi; push full MIDI message onto ring buffer
        contains: note on/off info, status message info
    handled in: event-triggered ISR

7. WAVETABLE MODE FSM

    handled by: event-triggered ISR
